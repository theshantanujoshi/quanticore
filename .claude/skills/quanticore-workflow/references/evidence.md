# Evidence contract

Record the repository revision and relevant dirty files. Tie model results to a named dataset, target mapping, split, feature schema, artifact path, and command. Cite `path:line` for static behavior and distinguish source inspection from tests and live inference. A successful test supports only the behavior it exercised. Report missing data, missing model artifacts, unavailable dependencies, and untested paths explicitly.

Never infer real-world calibration, fairness, regulatory compliance, or deployability from synthetic data, a Brier score, a healthy endpoint, or a README claim alone.
